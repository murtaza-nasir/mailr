# Known open-tracking images in email (core/trackers.py reads this file).
#
# One rule per line: a host, then optionally a regular expression for the path and query.
# - The host matches itself and its subdomains ("list-manage.com" covers "x.us1.list-manage.com").
# - "*" as the host matches every host: use it only for paths that are specific to one sender
#   platform's open pixel (custom tracking domains of SendGrid, Mailgun, SparkPost and others).
# - Without a path, every image from the host is a tracker. Use that only for hosts that serve
#   nothing else.
# The path pattern is matched case-insensitively against "/path?query" from its start.
#
# A tracker image is never fetched and is removed from the body; the reader counts it.
# Add rules as new platforms show up; tests/test_image_proxy.py checks a sample of them.
