# Keyboard shortcuts

Press `?` anywhere for the shortcuts of the page you are on. Turn shortcuts on or off with
`keyboard_shortcuts` (Settings → Look). Shortcuts match Gmail's where Gmail has one.

"g then i" means: press `g`, let go, then press `i`.

## Everywhere

### Go to

| Action | Keys |
|---|---|
| Go to Inbox | `g then i` |
| Go to Calendar | `g then c` |
| Go to Tasks | `g then k` |
| Go to Notes | `g then n` |
| Go to Recordings (with a Speakr account) | `g then r` |

### Application

| Action | Keys |
|---|---|
| Keyboard shortcuts | `?` |
| Command palette | `Ctrl + K` (`⌘ K`) |
| Close / clear | `Esc` |
| Settings | `Ctrl + ,` |
| Show or hide Ambrose | `Ctrl + .` |
| Rerun Ambrose's last reply | `Shift + r` |
| Ask Ambrose about what is open | `Shift + a` |
| New note (#List adds to a list) | `Shift + n` |

### Formatting

These keys work in a message you write.

| Action | Keys |
|---|---|
| Bold | `Ctrl + b` |
| Italic | `Ctrl + i` |
| Underline | `Ctrl + u` |
| Undo typing | `Ctrl + z` |
| Redo typing | `Ctrl + Shift + z` |

### In an open note

| Action | Keys |
|---|---|
| Make it a list / make it text | `Ctrl + Shift + 8` |
| New item below | `Enter` |
| The extra line of the item | `Shift + Enter` |
| In an empty item: delete it | `Backspace` |
| Check or uncheck the focused item | `Ctrl + Enter` |
| Move the item (or the section header) up | `Alt + ↑` |
| Move the item (or the section header) down | `Alt + ↓` |
| Move the item to the previous section | `Alt + Shift + ↑` |
| Move the item to the next section | `Alt + Shift + ↓` |
| New section after this one | `Alt + Enter` |
| Undo the last change in the note | `Ctrl + Z` (`⌘ Z`) |
| Redo | `Ctrl + Shift + Z` or `Ctrl + Y` (`⌘ ⇧ Z`) |
| Close (saves) | `Esc` |
